# Afforestt Home Page Redesign

A responsive front-end redesign of the Afforestt home page, completed as a UI/UX assignment.

## Assignment brief

Review the existing [Afforestt website](https://afforestt.com/), identify UX/UI issues, redesign a focused home-page section, and implement it as a modern responsive interface.

Afforestt restores native forests, supports CSR plantation projects, trains forest creators, and helps rehydrate land.

## Delivered

- Responsive home-page redesign for desktop and mobile
- Redesigned hero, service-selection section, impact section, and contact CTA
- Mobile navigation interaction
- Static front-end implementation using HTML, CSS, and JavaScript
- Existing Afforestt forest imagery reused in the design

## UX/UI issues identified

1. **The main purpose is unclear at first glance.** The original experience uses powerful imagery, but visitors need a faster explanation of what Afforestt does and why it matters.
2. **The primary action is understated.** A visitor who wants to start a project, collaborate, or learn more does not have a clear guided path immediately.
3. **Services are not easy to scan.** The main visitor intents—creating a forest, CSR partnerships, and training—should be visible as distinct choices.
4. **Impact and credibility are delayed.** Important proof points should appear near the introduction to build confidence quickly.
5. **Mobile navigation needs a more compact interaction.** The redesign adds a touch-friendly menu pattern for smaller screens.

## Changes made

- Added a focused headline: “Let the land remember forest.”
- Added clear supporting copy explaining Afforestt’s native-ecosystem approach.
- Added a prominent primary CTA: **Start a conversation**.
- Added concise impact highlights: years restoring landscapes, forests grown, and countries reached.
- Added three visual service cards to make key visitor paths easy to choose.
- Added a secondary impact section and a single, clear contact action.
- Built adaptive layouts, typography, spacing, and card structure for mobile and desktop screens.
- Added a functional hamburger menu on mobile.

## Technology used

- HTML5
- CSS3 (responsive layout with CSS Grid and media queries)
- Vanilla JavaScript
- Google Fonts
